# 두뇌 풀가동! 트리플 퀴즈 쇼

2026 충북 AI 페스티벌 체험 부스용 웹앱입니다. 초등학생이 만든 상식·연산·아재개그 퀴즈를 업그레이드했습니다.

- `index.html`: 업그레이드한 앱
  - 부스 도전: 이름을 적고 3라운드(상식 → 연산 → 아재개그) 12문제, 점수를 오늘의 랭킹에 올리기
  - 자유 연습: 분야, 문제 수, 제한 시간, 연산 수준 고르기
  - 2인 대결: 같은 문제를 동시에 풀어 먼저 맞히는 사람이 득점
  - 찬스 두 가지(50:50, 시간 +10초), 해설과 오답 노트
- `board.js`: 부스 공용 랭킹(Firebase). 다른 부스 앱과 같은 파일
- `원본_학생작품.html`: 학생이 만든 원본
